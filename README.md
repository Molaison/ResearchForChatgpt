# ResearchForChatgpt

A GitHub Pages archive for research reports generated by ChatGPT / agents.

## Site structure

```text
_config.yml
_layouts/
assets/css/site.css
index.md
reports/index.md
reports/template.md
research/YYYY/MM/DD/<slug>/report.md
```

## Report convention

Each report should live at:

```text
research/YYYY/MM/DD/<slug>/report.md
```

and start with:

```yaml
---
layout: report
title: Report title
date: 2026-07-02
status: completed
author: ChatGPT / Agent
summary: Short report summary.
tags: [example]
report: true
---
```

`report: true` makes the report appear automatically on the homepage and `/reports/` page during Jekyll build.

## Publishing

This repository includes `.github/workflows/pages.yml` to build and deploy the site with GitHub Actions.

One-time setup in GitHub UI:

1. Open repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Push to `main` or run the workflow manually.

Project site URL should be:

```text
https://molaison.github.io/ResearchForChatgpt/
```

Note: GitHub Pages sites may be publicly accessible even when the repository is private. Avoid publishing sensitive content.
